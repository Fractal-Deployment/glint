## Script errors found and fixed during the run (not GPU problems)
`build_p7_kernels` and `plug_selection` were first run in the wrong place (inside the container, which has no `lxc`); the Phi-4 streamer test
was missing two source files at link time; a root-owned file from the misplaced run blocked a rewrite. All three were fixed in the script and the
affected steps rerun (`RETEST_APPEND=1 RETEST_ONLY=regex`).

## Not made, and why
- **Qwen3-4B-Base (MS1 in the rules):** not on disk; fetching it is a download that needs your OK.
- **gemma-4-E2B / E4B:** the architecture is not supported by any glint forward harness here.
- **A full forward for DeepSeek / SmolLM2:** the Arm 0 harness hard-codes the Phi-4 shapes; a Qwen2/Llama forward is a new build, not a retest.
- **Phi-4-mini-nested-nf8 pin:** exists, but the harness that evaluated it (`p7_fold_eval.cu`) does not build in this repo; not retested.
